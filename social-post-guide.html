📣 社群自動發文 Skill 安裝手冊

Mac 零基礎版 — 不需要會 Git、不需要會寫程式，照著一步一步做、複製貼上就能完成。

🎒 開始前，你需要準備：
  1. 一個 Claude 付費帳號（Pro 或 Max 方案）— 到 claude.ai 註冊並訂閱
  2. Chrome 瀏覽器 — 還沒有的話到 google.com/chrome 下載安裝
  3. 你的 Facebook 個人頁要有至少 20 篇公開貼文（這個工具要拿來學你的說話風格）

第 1 步打開「終端機」（Terminal）

終端機是 Mac 內建的程式，長得像黑色或白色的文字視窗。打開方法：

  1. 同時按鍵盤上的 ⌘ Command + 空白鍵，會跳出搜尋框
  2. 輸入 終端機（或 Terminal）
  3. 按 Enter

會出現一個視窗，裡面有一行字、結尾有個游標在閃。這就是你要貼指令的地方。

💡 使用方式很簡單：按本頁指令右邊的「複製」按鈕 → 在終端機視窗按 ⌘+V 貼上 → 按 Enter 執行。每次都等它跑完（游標重新出現在新的一行）再貼下一條。

第 2 步安裝 Claude Code

Claude Code 是在終端機裡使用 Claude 的程式。複製下面這行，貼到終端機，按 Enter：

curl -fsSL https://claude.ai/install.sh | bash

跑完之後，把終端機完全關掉（按 ⌘+Q），再重新打開一次（重複第 1 步）。這步很重要，不然電腦會找不到剛裝好的程式。

重開後，輸入這個並按 Enter：

claude

第一次執行會請你登入：它會自動打開瀏覽器，用你的 Claude 帳號登入並按「授權」即可。登入成功後回到終端機，先按 Ctrl+C 兩次離開 Claude（我們等一下還要做安裝）。

❗ 如果輸入 claude 後出現 command not found，代表你沒有重開終端機，請按 ⌘+Q 關掉再開一次。

第 3 步下載 Skill（不需要 Git）

  1. 用瀏覽器打開這個網址（打開就會自動下載一個 ZIP 檔到「下載項目」資料夾）：
    👉 https://github.com/Hao0321/claude-skill-social-post/archive/refs/heads/main.zip
  2. 打開 Finder → 下載項目，找到 claude-skill-social-post-main.zip
  3. 點兩下這個 ZIP 檔，它會解壓縮成一個叫 claude-skill-social-post-main 的資料夾
    （如果下載完已經自動變成資料夾、沒有 ZIP 檔，那就直接跳下一步）

第 4 步把 Skill 放到正確位置

Skill 要放進一個隱藏資料夾，用 Finder 找不太到，所以我們用終端機來搬。回到終端機，一行一行複製貼上、每行按一次 Enter：

mkdir -p ~/.claude/skills
cp -r ~/Downloads/claude-skill-social-post-main/social-post ~/.claude/skills/social-post
cd ~/.claude/skills/social-post
mv style_profile.example.md style_profile.md
mv content_plan.example.md content_plan.md

最後檢查一下有沒有成功，貼上這行：

ls ~/.claude/skills/social-post
✅ 如果有列出 SKILL.md、style_profile.md、content_plan.md 之類的檔案名稱，就代表安裝成功了！
❗ 如果第二行出現 No such file or directory，通常是 ZIP 還沒解壓縮（回去做第 3 步的點兩下），或是檔案不在「下載項目」資料夾。

第 5 步安裝「Claude for Chrome」瀏覽器擴充功能

這個 skill 要靠 Claude 操作你的 Chrome 瀏覽器來自動發文，所以需要裝官方擴充功能：

  1. 打開 Chrome
  2. 前往 Chrome 線上應用程式商店，搜尋 「Claude for Chrome」（Anthropic 官方出品），按「加到 Chrome」
  3. 點 Chrome 右上角的 Claude 圖示，用你同一個 Claude 帳號登入
  4. 在 Chrome 裡登入你要發文的社群帳號：Facebook、Instagram、Threads、X（要發哪些就登入哪些）
💡 如果商店搜不到或無法安裝，可以到 claude.ai/chrome 看看，這個功能可能需要特定方案或申請開通。

第 6 步開始使用 🎉

以後每次要用，流程都一樣：

  1. 打開終端機（⌘+空白鍵 → 輸入 終端機 → Enter）
  2. 輸入 claude 按 Enter
  3. 直接用中文跟它對話，主要有三句咒語：
你打的字它會做什麼
幫我學 FB 風格讀你最近 20 篇貼文，學會你的語氣（第一次先做這個）
幫我排社群內容日曆幫你規劃 14 天的發文計畫
今天發一篇問你今天的素材 → 寫草稿給你看 → 你確認後自動發文

過程中 Claude 可能會問你「是否允許執行某動作」，看一下內容沒問題就選允許。發文前它一定會先給你看草稿，你說 OK 它才會發，不用擔心亂發。

用完想離開，按 Ctrl+C 兩次，或直接關掉終端機視窗。

⚠️ 自動發文是對外公開的行為。第一次發文時建議全程盯著看草稿和發布過程，確認沒問題再放手讓它自動跑。
